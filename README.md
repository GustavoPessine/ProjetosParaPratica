Projetos e Desafios de Lógica (JavaScript)
Este repositório contém projetos desenvolvidos para consolidar fundamentos de programação, lógica e manipulação do DOM com JavaScript.

🎲 Sorteador de Números
Foco: Lógica inicial e manipulação de arrays.

O que aprendi: Implementação de variáveis, conexão entre HTML e JavaScript, e reforço em estruturas de repetição (for/while), condicionais e métodos de arrays.

🎮 AluGames
Foco: Manipulação do DOM.

O que aprendi: Recuperação de elementos com getElementById e querySelector. Pratiquei a alteração dinâmica de estados (adicionar, remover e alterar classes ou elementos HTML).

🛒 Carrinho de Compras
Foco: Tratamento de dados e formulários.

O que aprendi: * Uso do método .split() para manipulação de strings (separação de nome e preço).

Captura de valores em formulários e dashboards.

Uso de Template Strings para renderizar novos itens na interface de forma dinâmica.

🎫 Ingressos Online
Foco: Conversão de tipos e funções específicas.

O que aprendi: Uso de parseInt() para garantir cálculos matemáticos precisos entre strings do HTML e números. Implementação de funções modulares para validar a disponibilidade e subtração de estoque de ingressos.

🎁 Amigo Secreto
Foco: Algoritmos, validações e bibliotecas.

O que aprendi: * Implementação de algoritmos de embaralhamento de arrays (Fisher-Yates).

Criação de validações robustas: impedimento de nomes duplicados, campos vazios e limite mínimo de participantes.

Introdução a conceitos de tratamento de erros e a percepção de que diferentes linguagens possuem sintaxes distintas (como try/catch no JS).
