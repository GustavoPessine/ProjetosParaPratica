Projetos/Desafios para prática!

Cada Desafio aqui é um projeto que foi desenvolvido de forma simples para melhorar a lógica e a afinidade com o JavaScript

- Sorteador-Números: Site para sorteio de números, foi estudada e desenvolvida a lógica inicial de variáveis, a conexão do HTML com o JavaScript e foi reforçado o conhecimento de condicionais, repetições, e array, nesse Projeto.

- AluGames: Site para aluguel de jogos, projeto Simples, feito com foco em analisar o código HTML, recuperar os elementos da página com getElementById e querySelector, e adicionar, alterar e remover elementos do HTML.

- Carrinho-compras: Site para adicionar produtos em um carrinho, aprendi: a função split, que separa um valor a partir de um ponto, assim o valores ITEM_PREÇO, são separados como ITEM e PREÇO de um produto, recuperar valores de um formulário HTML, compreendi melhor oque são formulários e dashboards no HTML e como selecionar valores e clicar nos itens de cada um para além de obter os valores, ativar a função que utiliza tais valores ou altera os itens, e revi o uso de template Strings para adicionar itens a uma seção do HTML.

- Ingressos-Online: Site para compra de ingressos, foi reforçado o uso do parseInt() para a conversão de uma string do HTML em inteiro para comparação com outro inteiro, e dependendo do tipo de ingresso escolhido, será ativada uma função para o ingresso, funções que garantem a compra e subtraem os ingressos restantes.
